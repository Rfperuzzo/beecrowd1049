# 🐾 Beecrowd 1049 — Animal

Solução desenvolvida em **Java** para o exercício **1049 — Animal**, da plataforma Beecrowd.

O objetivo do exercício é identificar um animal a partir de três características fornecidas na entrada.

---

## 📚 Objetivo

Este exercício trabalha principalmente com:

- Entrada de dados com `Scanner`;
- Comparação de `String`;
- Estruturas condicionais;
- `if`, `else if` e `else`;
- Condições aninhadas;
- Tomada de decisão;
- Lógica de classificação.

---

## 🧠 Lógica do problema

O programa recebe três palavras que representam características de um animal.

A identificação acontece através de uma árvore de decisões.

Exemplo:

```text
vertebrado
mamifero
onivoro
